🧮 Python Calculator Application
📌 Project Overview
This project is a collaborative Python Calculator Application developed using Git and GitHub. The objective of
this project is to demonstrate teamwork, version control, branching, pull requests, and code integration while building a 
calculator that performs multiple mathematical operations.
Each team member is responsible for implementing one calculator operation in a separate Git branch and merging it into the main branch through a Pull Request (PR).
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------
🎯 Project Objectives
Learn Git and GitHub collaboration.
Understand branching and merging concepts.
Practice creating and reviewing Pull Requests.
Develop a calculator application using Python.
Work effectively as a team on a shared repository.
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------
⚙️ Features
The calculator supports the following operations:
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🔼 Power
📊 Modulus
🔽 Floor Division
----------------------------------------------------------------------------------------------------------------------------------------------------------------------
👥 Team Workflow
Step 1: Create Repository
Team Member A creates a GitHub repository.
Repository access is shared with all team members.
----------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 2: Clone Repository
Each team member clones the repository to their local machine.
Bash
git clone <repository-link>
---------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 3: Create Branch
Each member creates a separate branch using the format:
Bash
<operation>-<student_name>
Example:
Bash
addition-rohan
subtraction-rahul
multiplication-priya
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 4: Implement Assigned Operation
Each member develops their assigned calculator operation in Python.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 5: Commit Changes
Bash
git add .
git commit -m "Added addition operation"
-------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 6: Push Branch
Bash
git push origin addition-rohan
-------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 7: Create Pull Request
Open GitHub.
Create a Pull Request from your branch.
Request review from team members.
------------------------------------------------------------------------------------------------------------------------------------------------------------------
Step 8: Review and Merge
Review the code.
Resolve conflicts if any.
